# Dynamic Programming Repository

This repository contains a collection of **Dynamic Programming (DP) problems** with clear, step‑by‑step explanations.  
The goal is to help learners understand how to break down complex problems into smaller subproblems and solve them efficiently.

---
## 🧩 What’s Inside
Each problem includes:
- **Problem statement** (short and clear)
- **Approach** (recurrence relation or state definition)
- **Code solution** (well‑commented)
- **Brief explanation** (intuition behind the steps)

---

## 🎯 Purpose
- Build strong intuition for DP.
- Learn common DP patterns (subsequences, knapsack, grid problems, etc.).
- Practice writing optimized solutions.

---
## 📖 Example
**Problem:** Fibonacci Sequence  
**Approach:** `dp[i] = dp[i-1] + dp[i-2]`  
**Explanation:** Each term is the sum of the previous two.  
**Solution:** See `Solutions/fibonacci.cpp`
